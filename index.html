My PC still went to sleep

Check that the tray cup is amber. Closing the lid of a laptop or pressing the power button still puts it to sleep — that is a hardware action AwakeKit does not override. Some company policies can also force sleep.

My chat status still goes to "Away"

Turn on Mouse jiggler in the Awake tab (or the tray menu). Some apps also need the screen on — enable Keep screen on. If an app running as administrator is in front, Windows blocks input from normal apps; switch to another window.

How do I see that AwakeKit is working?

Open an administrator command prompt and run powercfg /requests. While AwakeKit is active it is listed under SYSTEM (and DISPLAY if Keep screen on is enabled). After you click Stop, the entry disappears.

I bought Pro but the app still says Free

Sign in to the Microsoft Store with the account you bought it with and reopen AwakeKit. Still stuck? Email us.
